# homebrew-darichat

[다리챗](https://darichat.com) 데스크톱 앱과 `dari` CLI 를 Homebrew 로 설치한다.

```bash
brew install --cask librorum/darichat/darichat  # 맥 데스크톱 앱 (dari CLI 도 같이 설치)
brew install librorum/darichat/dari            # CLI 만 (macOS·Linux)
```

- 데스크톱 앱은 스스로 업데이트한다.
- CLI 는 `brew upgrade dari` 로 업데이트한다.
